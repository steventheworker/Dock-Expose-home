Dock Exposé 4.00.3 release notes

Changes since v4.00.2:

  • Each exposé window now gets 1 set of window-for-all-controls (was 1 per control).
  • Expose bar flashes on top for a second before sinking behind thumbnails.
  • Expose bar sits behind window thumbnails and rises on hover.
  • Cmd-clicking a recent item reveals it in Finder.
  • Expose controls now match windows by tile frame, not title.
  • Mission Control space titles are sized to the titles, not the screen.
  • Mission Control uses one container per display with a subview per space.
  • Mission Control editable space titles follow the expanding top strip.
  • Mission Control overlays rebuild on the now-active space when it changes.
  • Mission Control detects the end of a window drag by polling the button.
  • Expose bar flash prevents immediate tuck when entering preview windows.
  • The ~1s main-thread stall at the start of every expose has been fixed.
