Dock Exposé 4.00.4 release notes

Changes since v4.00.3:

  • Fix window description race on title/subrole, filtering non-retryable attributes
  • Fix dead Window.subrole (dangling direct-ivar store)
  • Default Zoom Delay set to 1.2s; only nudge when switching windows
  • Escape undoes zoom, Return activates the zoomed window
  • Skip entry flash when cursor is already on an exposed window
  • Ensure folder preview on exposé close if mouse settled on dock folder
  • Sink expose controls behind Space key zoom in Mission Control & App Exposé
  • Order minimized windows by space then minimize time
  • Fall back to Dock's mc group on macOS <= 26 for window titles
  • Fix CF ownership leaks across attr:/attrs:/Create results
  • Hover preview: debounce settle re-check with one timer; re-check hover once mouse settles
  • Keep App Exposé open over Space-zoomed window gaps; zoom auto-zoom nudges pointer before zooming; handle activateFromApplication when process is attached to Xcode; bound AX retry budget and keep space-change reads off main thread
