Dock Exposé 4.00.2 release notes

Changes since v4.00.0:

  • Hide overlays as the close animation begins
  • Exit App Exposé when closing the last non-minimized window (wait 333ms)
  • Let clicks dismiss an open Dock context menu
  • Open a window when launching a not-running Finder
  • Send new-window Cmd-N to the app's process
  • Never collapse while QuickLook is open
  • Collapse on leave, resync state, keep open while scrolling
  • Reflect a recent's new order after clicking it
  • Raise the bottom bar for the first minimize while expose is open
  • Rebuild when the minimized set changes
  • Add tick marks to delay sliders
  • Add Preview Folders setting
