Dock Exposé 4.00.1 release notes

Changes since v4.00.0:

  • Dock clicks open the Trash when it launches a not-running Finder.
  • Dock clicks let users dismiss an open Dock context menu.
  • Dock clicks send new-window Cmd-N to the app's process.
  • Windows only preview root, non-auxiliary surfaces.
  • Window controls follow a window created while expose is open.
  • Window controls follow the grid while a minimize animates.
  • Window controls exit App Exposé when closing the last non-minimized window.
  • Folder preview never collapses while QuickLook is open; collapses on leave and resyncs state.
  • Bottom bar reflects a recent's new order after clicking it, raises it for the first minimize, and rebuilds when the minimized set changes.
  • Hover preview adds a Preview Folders setting.
