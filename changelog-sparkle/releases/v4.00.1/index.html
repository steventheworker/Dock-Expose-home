Dock Exposé 4.00.1 release notes

Changes since v4.00.0:

    Fixed bugs/crashes:
  • Restore ubuntu/click-to-preview (Linux) mode.
  • Shift+Click dock icon (new window) now works while App Exposé is open.
  • Mission Control / App Exposé close button/title positions were stale after close/minimize.
  • Clicking out of a context menu (on a dock icon) would also run the dock icon action (hide/unhide etc.).
  • App auxilliary windows (i.e. panels) were counted as previewable windows.
  • Individual tabs were counted as previewable windows (for apps using native macOS tabs).
    • Other:
  • Add "Preview Folders" Setting.
  • Exit App Exposé when closing the last non-minimized window.
  • Recent items list updates as you open or delete.
  • Trash/Finder click (and not running) -> launch + make new window.
