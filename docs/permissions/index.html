Permissions and setup

Dock Exposé asks for permissions before it starts observing the Dock and windows.

Required

  • Accessibility lets Dock Exposé read and interact with Dock, application, window, Mission Control, and App Exposé accessibility elements.
  • Screen Recording is needed for minimized-window thumbnails in the custom bottom bar.

Optional

Full Disk Access is needed by the Recents Editor to read and edit per-application recent-document lists. Without it, recent documents may be absent, while other features continue to work.

Input Monitoring is not required by Dock Exposé 4.00.1.

First launch

The setup window opens System Settings for the required permissions and waits for them to be granted. If macOS does not update the status immediately, return to Dock Exposé and use Refresh or relaunch the app.

Dock Exposé 4.00.1 is not notarized. macOS may require you to right-click the app and choose Open the first time it is launched.
